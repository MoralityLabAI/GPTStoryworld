# PP2-BAL-06: certified-edit proposal learning
Protocol frozen before generating the six fresh evaluation grids. Source: PP2-BAL-05's six development receipts, with three generator families. Primary: train on the four development roots from the other two families, test on two fresh coefficient roots of the excluded family (three folds). Secondary: train on all six development roots and test on the same six fresh roots. No seed overlap. Development transfer test, not independent external or sealed evaluation; only three known synthetic generators.

The candidate evaluator remains the native reader and rational 1/5-regret robustness verifier. The learner is a small CPU ridge proxy, not a native TRM or BPD weight decomposition. Eight edit-direction blocks (four p/p2 groups times up/down); two heads per block predict hard-gate passage and change in J=L_author+W. Fixed ridge 4. Numeric delta labels use only source and target with exact objective intervals. Gate labels use all valid grid edges. Parent features: already evaluated screen metrics, ending-cell frequencies, current grid and proposed next level; static target, authored terminal utilities and site counts. No family ID, seed, test target metric, refined test interval, or unseen game index is a feature. Direction-only control uses the same training marginal means. Shuffled control permutes the paired gate/delta labels within each training root and edit direction, retaining marginal means and missing-label counts. No tuning on fresh outcomes.

All search arms start at the same base, use only an oracle for previously unevaluated candidates and accept an incumbent only if p and p2 ablation TV >=1/8, uniform dead/horizon mass=0 and a verified equilibrium witness exists. Infeasible visited candidates may be used to explore. Frozen screen upper J orders admitted incumbents with edit-count/key ties. Compare 8,16,32 unique candidate queries on a single nested trajectory: gated frontier, parent-score priority, direction-only, learned, shuffled, random-local and random-global (one fixed seed per root). Learned priority = parent upper J + clipped predicted delta + 1-clipped predicted gate probability. Equal candidate counts, not equal runtime. The table oracle exposes only the same fields available from an actual screen call; the complete native-generated grids establish offline truth. Refined test intervals only score outcomes after search. Exact optimum hit when incumbent upper J equals minimum admitted grid lower J; paired wins/losses require interval separation or an admitted incumbent versus none. Ties require equal exact objective, otherwise unresolved. Report no-incumbent separately. No promotion unless benefit is visible against the nonlearned and shuffled controls. Fresh grids replay native reader; no model training on those grids. Future native TRM/BPD requires a separate training harness and interventions.
