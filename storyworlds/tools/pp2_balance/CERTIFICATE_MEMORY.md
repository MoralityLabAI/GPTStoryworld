# PP2-BAL-10: bounded certificate retrieval

Frozen before training or fresh evaluations. Train only on the six spent PP2-BAL-08 roots and their two PP2-BAL-09 trajectories. For each identity miss not solved by early pure proof, generate single-source transport labels from at most eight prior distinct game proofs in an LRU cache. Source pools contain previously verified cold certificates. Measure exact work on transport including target re-verification, plus independently measured cold fallback. Label net rational normalizations saved: (cold cost if hit, else zero) minus transport cost, scaled by 100000. Early pure is common and omitted from the label; measured separately. Family-held-out fixed ridge 4, one scalar reward head, sham shuffles labels within root. Features are current evaluated matrix and stored proof only: age, ending mismatch, payoff differences, approximate witness regret and TV on target, support/dual statistics and interval width. Floating features may order proposals but never certify them. No target cold result or actual transport outcome is available to the retriever. Compare cache-only, recency, ending-Hamming similarity, approximate witness feasibility heuristic, learned utility and shuffled utility. Common cap eight total game identities and maximum two sequential source attempts per miss. Identity hits touch LRU; source retrieval does not touch LRU. Early pure before retrieval, full cold fallback after failed transport. No hidden unbounded controller cache; outer audit records are not exposed to controllers. Peak profile and dual counts reported as well as entry counts, no byte-level memory guarantee.

Fresh roster: six new roots from the same three known synthetic generator families. Each root streams two 64-query prospective trajectories generated online by the cache-only reference (parent priority and random-global). Native reader measures and extracts each query once, streams identical matrices to independent bounded controllers, retains proof receipts for audit. All arms see the same sequence and target; only reference observations determine the next edit. No live policy divergence claim. Independent cold computation per query AFTER the trajectory verifies each output interval is no weaker, witness status preserved, and rechecks every proof. Exact equality vs tighter certificate counted. All online meters include cold fallback, failed transport, early pure and target verification; retrieval features count matrix/profile cells, linear terms and comparisons separately. These are operation counts; not bit complexity, measured wall time, or end-to-end speedup. Native transitions shared and reported. Training work separate. No promotion of learned retrieval unless savings against strong fixed controls are supported by paired roots. Restricted two-player synthetic policy rosters; no actual authored worlds changed. Replay node certificate_memory_replay.mjs; --write regenerates receipts. No native BPD or TRM training.
