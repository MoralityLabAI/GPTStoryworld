# PP2-BAL-07: independent full-keyring edits and recurrent proposal training

Development protocol frozen before sampling or fitting. Existing six PP2-BAL-05 roots are training roots. Three held-family-out folds fit on four roots each; six fresh evaluation seeds (two per family) are declared in coordinate_gym.mjs. No training on fresh roots, no seed overlap. All families were previously studied, so this is developmental generator transfer, not a sealed external benchmark.

Split the approved sites into (effect/read group, character, full keyring). Eight chain blocks and nine fork/veto blocks, four gains each, with baseline gain 1. Independent positive scalar edits preserve the original sign, keyring, topology, narrative and approval. Common group gains replay the original patch exactly. Candidate evaluation uses native reader enumeration, explicit restricted two-player policy rosters, exact rational regret and certified robust-TV screen from PP2-BAL-05. Admitted incumbent requires a verified equilibrium witness, both perception ablation sensitivities >=1/8 and zero dead/horizon mass. Evaluated rows include certificate data by deduplicated game. No global optimum claim for 4^8 or 4^9 grid; no unvisited test candidate metrics available to proposal models.

Training: 20 fixed-seed anchor grids per train root, eight shuffled unique local edits per anchor (up to 160 directed examples per root). Numeric delta labels only where both endpoint robust J intervals are exact; admission label always observed. Features include already evaluated parent metrics, group/owner/keyring categorical roles, proposal level and direction, same-group gain means, authored utility/target and site statistics. No family/seed feature. Three-pass compact two-state weight-tied learner (TRM-style, standalone JS implementation; not upstream TRM or native BPD): e=tanh(Wx+b); initialize z=y=e; z'=tanh(Az+By+e+bz); y'=tanh(Cz'+Dy+e+by). Shared readout at each pass predicts admission and delta J. Loss averages over passes, with gate weight .25 and delta weight 2, missing delta masked. Full analytic BPTT, finite-difference gradient check, hidden size 8, 12 shuffled SGD epochs with gradient clipping and fixed seed. Controls: same parameters at one pass, three-pass label-shuffled (within root/group/direction preserving paired label and missingness marginals), directional means, parent-priority, original gated frontier, random-local and random-global. Single initialization per model; same optimizer steps, not matched FLOPs. No native BPD decomposition claimed.

Evaluation: all policies start at baseline, use exactly 8/16/32/64 unique candidate queries on nested trajectories. Each search's visible observations are independent; underlying computation can be cached across policies. Rank eligible incumbents by exact screen upper J, with deterministic ties. Proposals use predicted delta and admission probability only; no learned acceptance. Compare pairwise exact interval separation, report missing incumbents, and gap to best observed upper J in union of evaluated profiles and independent post-search probes. That gap is relative to a sampled reference, not to the global optimum. Proposal priority quantized to 1e-9 for deterministic replay. No test-set retuning.

Interventions: select one physical column of shared D by training-only variance-weighted squared column norm. On each pass replace the column contribution using the mean training activation for that pass, retaining all other contributions. Compare a same-preactivation-L2 signed random-direction null, including all-pass intervention. Evaluate clean vs intervened gate accuracy, delta MSE, output shift on 12 fresh anchor grids x six local probes after search, without training. These are rank-one write interventions inspired by BPD, not trained BPD factorization; null is Rademacher, not Haar. Results remain exploratory. No production world changed. Replay via node recurrent_replay.mjs; --write writes receipts. CI will be added after receipts exist.
