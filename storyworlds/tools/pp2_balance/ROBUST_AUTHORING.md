Fixed roster: two fresh coefficient seeds for each of chain (existing), fork (branch-specific intermediate encounter, state-gated final option) and veto (possible early defection, state-gated final option). The two added families are synthetic structural variants; no real authoring or sealed claim.

Enumerate every one of 256 grid points per root, measuring PP2-BAL-01 author loss and extracting the game via the native reader. Deduplicate exact matrices including ending IDs and policy IDs per root. First screen exact feasible pure/uniform and support-only profiles. For any ending distribution supported by the ending cells, TV <= max_e(1-q(e)); if a feasible witness attains this upper bound then worst TV is certified exactly. Otherwise obtain a rational PP2-BAL-04 dual relaxation with zero cover splits, retaining an honest interval. A failed witness search leaves an unresolved interval, not a certificate of infeasibility. Verification recomputes every bound and witness.

Use a 16-candidate matched frontier search on author loss vs upper J; the full grid is only used as a lookup table and the search only consults visited scores. Assert baseline visitation parity against balance.mjs. For the exhaustive arm, refine at most four distinct competitive non-exact games using 128 simplex splits; intersect independently checked intervals. Select the lowest certified upper J, and record the lower bound min J_lower across all 256 candidates. If the interval closes, the grid objective is globally minimized; if not, report the exact residual gap. No continuous parameter optimality claim. Also retain a constrained worst-TV arm preserving the minimum full-grid author loss. Matched frontier arms use frozen screen scores, with refined certificates only for reporting; search cost is matched by candidate count, not actual compute.

Receipts: every candidate includes grid, game index, author loss, p/p2 sensitivity, horizon/dead mass, worst TV and joint loss intervals. Unique games contain exact certificate data. Reverse directions are derivable. These are DataGoblin training candidates with explicit root/family IDs and no claim of native training, held-out generalization or production applicability.
