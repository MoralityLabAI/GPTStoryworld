# PP2-BAL-10 results: bounded certificate memory

Prospective development campaign: 6 fresh coefficient roots, 12 trajectories, 768 queries per arm, 96934 shared native reader transitions. Each retrieval model excludes the test generator family from training. All six arms independently preserve the cold-reference interval and witness-availability flag on all queries. Memory cap: eight resident identities; maximum two sequential source attempts per miss. Training: 1018 single-source pairs, 316 successful exact transports; fit is a 15-feature ridge model. The training label is net measured rational normalization savings versus cold fallback, after the shared early-pure screen.

Lowest rational normalization count: feasibility (3066443). Learned reduction relative to cache-only: 61.94%. Learned vs feasibility: 1 trajectory wins, 4 losses, 7 ties. The learned arm also pays 8970 extra linear scoring terms. No learned promotion: its work count does not establish a benefit beyond the fixed geometry/feasibility controls. Retain bounded exact proof reuse and the deterministic feasibility baseline for further prospective trials. The synthetic roots share the known three structural generators; parent-priority and random-global paths are chosen by the cache-only reference, so this is a matched online matrix-stream evaluation rather than a closed-loop search comparison between retrieval policies. Rational normalization and comparison calls are measured separately from retrieval feature and native reader work; no bit-complexity, memory-byte, or wall-time claim. The audit retains large proof receipts outside the controller and is not available to retrieval. Single fixed split/fit; no native BPD/TRM training.

Replay: node storyworlds/tools/pp2_balance/certificate_memory_replay.mjs. The six fresh test receipts contain target proofs, actual source attempts, exact cold checks, online counts and memory statistics. Hosted CI pending at commit creation.
