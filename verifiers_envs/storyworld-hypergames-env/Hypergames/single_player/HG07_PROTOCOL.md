# HG-07: Raw-state recurrent goal learning (frozen 2026-11-17)

The purpose is to test whether a small weight-tied recurrent network discovers six-coordinate parity goals from raw binary state vectors. HG-06 supplied exact two-bit fragments; HG-07's task-only models receive **only raw x and goal labels**. Fragment targets are reserved for a privileged auxiliary-training condition. The held-out HG-03 private-seed manifest is excluded.

The registration fixes six evaluation seeds, separate development seeds, 140-D core, 512-D padded and 512-D native cohorts, output ranks 1/2, train sizes 512/2048, 256-example calibration and 256-example test sets, and 350 CPU AdamW updates at batch size 128. Neural arms are a transparent linear classifier, a one-pass flat cell, a three-step tied recurrent cell, and tied cells with true or shuffled fragment auxiliary targets. Shared neural width is 64. Flat and looped share parameter shapes and gradient-update budgets; looped executes more forward operations.

Every neural run reports direct goal-head performance. The true-aux and shuffled-aux arms also report an XOR composition of the three learned pair-head threshold predictions. The true-aux composed readout benefits from privileged training labels for the actual hidden decomposition and must be labelled accordingly.

Use only calibration outcomes to choose release. If (256-cal-correct+1)/258 was used, it would be an error: the required posterior estimate is (cal-correct+1)/258. Release iff this estimate > 3/5. Payoffs: correct +10, incorrect -15, abstain 0. Report false-release counts. The GF(2) raw-state interpolator is an exact structural baseline and identifies a full row uniquely only when its rank posterior permits it; it must abstain when its fitted parity is observationally ambiguous. The true-goal oracle is privileged. For each task, 100 independently sampled six-sparse rank-k random parity bases receive the same training-label budget and signed fitting but are not compute matched to neural training.

Primary claims H1-H4 and all directions are in the immutable JSON registration. Success means evidence on the preregistered public synthetic generator; a failure is reportable. Preserve every per-seed outcome, the local source hashes, runtime/library versions, a replayable training script and separate exact EvalMath proofs. No model weights or external calls are required.
